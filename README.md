# Stock Analyzer

A Java-based web application that displays real-time and historical stock data, powered by the Yahoo Finance API. No API key required.

---

## Features

- **Live Intraday Data** — today's high, low, last price, and % change with a live indicator
- **Price Charts** — interactive chart with a Today (5-min bars) and 5 Days (daily) view
- **Highest Single-Day Swing** — scans 10 years of history to find the day with the biggest High−Low range
- **Top 10 Swing Days** — ranked table of the most volatile trading days on record
- **Autocomplete Search** — type any ticker or company name and select from a live dropdown
- **Any Ticker** — supports any publicly traded stock or ETF on Yahoo Finance

---

## Usage

1. Type a ticker (e.g. `AAPL`, `TSLA`, `SPY`) or a company name in the search bar
2. Select from the autocomplete dropdown or press **Enter**
3. Switch between **TODAY** and **5 DAYS** chart tabs
4. The **Champion Day** card shows the single largest intraday swing across 10 years of data
